# Contributing

Bug reports and reproducibility improvements are welcome.

1. Create a focused branch.
2. Preserve the mathematical update order and committed-update counter.
3. Add or update a numerical test when solver behavior changes.
4. Run `python -m pytest` before opening a pull request.
5. Describe any parameter or result-schema change in the pull request.

Please do not add third-party algorithm implementations without confirming their license and adding the appropriate attribution.
