# Clean MNIST input manifest

`mnist_clean_images.npz` contains the ten fixed MNIST images used by the image-denoising experiment.

- SHA-256: `a4954ccdc601ba031447b6b2dd6418715ce0a30c453fa297062e7fdbcab649b3`
- `digits`: uint8, shape (10,), values 0 through 9.
- `images`: float64, shape (10,28,28), clean normalized image pixels in [0,1].
- The image at index i corresponds to digits[i].
- Noisy images are generated by the experiment runner; no network download is required.
- Source: MNIST, https://yann.lecun.com/exdb/mnist/ . Cite LeCun, Cortes, and Burges (see `REFERENCES.bib`).
- The upstream sample indices and train/test split were not provided with the selected images. The exact array and hash specify this release's inputs.
